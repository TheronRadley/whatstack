### 🔍 Overview

**WhatStack** is a high performance developer tool built for immediate, deep dive technographic auditing. Unlike standard tools that only scrape simple script tags, WhatStack dynamically evaluates live runtime environments, DOM mutations, network footprints, security postures, and indexing architectures, rendering them inside a sleek, cyber minimalist dashboard.

### 📦 Core Engineering Modules

* **Frontend Intelligence:** Maps execution environments (React, Vue, Angular), component systems (Tailwind, Radix), CMS layers, custom typography engine routes, and telemetry pixels.
* **Infrastructure Tracking:** Traces global CDN distributions, web server variants (Nginx, Apache, LiteSpeed), and real time SSL TLS cipher and expiry parameters.
* **Network and Live DNS Routing:** Executes concurrent server side asynchronous resolution loops for A, AAAA, MX, CNAME, and TXT structures alongside geographical IP tracking.
* **Security and Optimization Auditing:** Validates critical modern HTTP safety layers (CSP, HSTS, X-Frame-Options) and extracts structural SEO data instantly.

### 🚀 Local Engineering Setup

#### Prerequisite Specifications
Ensure you have the latest LTS versions of **Node.js** and **npm** installed.

1. **Clone and Initialize Environment:**
   ```bash
   git clone https://github.com
   cd whatstack
   ```

2. **Deconstruct and Install Dependencies:**
   ```bash
   npm install
   ```

3. **Compile Production Extension Bundle:**
   ```bash
   npm run build
   ```

4. **Mount Target Assembly to Chromium Engine:**
   * Launch a Chromium based browser and target `chrome://extensions/`.
   * Enable the **Developer mode** toggle interface in the upper right quadrant.
   * Select **Load unpacked** from the operational configuration header.
   * Target the compiled production wrapper directory (`/dist` or `/build`) generated by the compiler.

### 🛠️ Core Technology Profile

* **Frontend Interface Layer:** React 18, TypeScript, Vite Bundler Core.
* **Styling Architecture:** Tailwind CSS Engine, Lucide Icons Framework.
* **Target Engine Specification:** Google Chrome Extension Platform Manifest V3.
